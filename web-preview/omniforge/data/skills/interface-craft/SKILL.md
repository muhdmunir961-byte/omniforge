# Interface Craft: Senior-level UI/UX

## Activate
Use for websites, SaaS, dashboards, landing pages, developer tools, Figma-derived interfaces, React, Next.js, HTML or CSS designs. Begin with source code and reference images; do not replace a working product blindly.

## Method
1. Inspect existing structure: target audience, main task, brand assets, content hierarchy, navigation, components, CSS variables and implementation framework.
2. Set one visual thesis: editorial minimal, architectural, classic industrial, heritage premium, or restrained technological. Make typography, whitespace, color, shape and imagery consistent. Avoid AI-slop decoration.
3. Map each page as intent -> input -> process -> output -> proof -> next action. Genuine copy and real links; no invented clients, testimonials, live charts or statistics.
4. Design tokens for foreground, background, surface, muted, divider, focus, success, danger, scale, spacing, radii and typography. Prefer 1-2 accent hues and intentional contrast.
5. Build reusable components and actual behavior: mobile menu, forms, loading/error/empty/success states, keyboard support, tabs, focus management and accessible semantics.
6. Audit at 360, 390, 768, 1280 and 1440 CSS pixels. Check text wrapping, gutters, clipped images and horizontal overflow. Use touch-friendly controls, distinguish hover from tap.
7. Meet WCAG AA color contrast goals (normal text 4.5:1, large text 3:1), reduced-motion, semantic landmarks, real input labels and clear focus rings.
8. Minimize fonts, dependencies, third-party scripts, layout shift and heavy animations. Make 3D optional, lazy loaded, and accessible via a non-3D fallback.
9. Iterate three times: user journey, visual art direction, browser functional verification. Capture before/after with desktop/mobile screenshots and Playwright results where available.

## Refuse generic UI patterns
No wallpaper-style blur blobs, random neon gradients, repetitive equally sized cards, fake command typing or mismatched cartoon icons. Do not increase visual complexity merely to look premium. Use authentic product screenshots, realistic data and measured functionality.

## Deliver
Page map, design tokens, files changed, rationale, responsive states, accessibility notes, screenshots/browser checks and remaining limitations. Separate design judgement from verified performance.

## Security boundary
Instructional skill only. Does not install Figma, fonts, design packages or browser tools. Require host approval for code writes, installing dependencies, network calls and deployments.
