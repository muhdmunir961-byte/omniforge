Recorded evidence vs live execution

This showcase replays archived CLI outputs and E2E assertions. The separate Live Python Terminal runs a real but strictly allowlisted OmniForge CLI in a new temporary project on Vercel. Its arbitrary Python playground runs in your browser via WebAssembly, not on our server. Neither mode provides your PC files, a wallet, unrestricted shell access or production integrations. Real project execution remains local and requires approval.
