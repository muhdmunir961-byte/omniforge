# OmniForge

Open capability layer for AI coding agents.

**Version:** 1.0.0 (local core build)

OmniForge combines a lazy-loading skill registry, a local CLI, an MCP stdio bridge, and VS Code integration. Its goal is to help coding agents find and load relevant skills without filling context with every skill document.
