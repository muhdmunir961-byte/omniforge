# Security Policy

OmniForge's skill documents and scripts should be treated as executable third-party software whenever installed or invoked. Inspect source and dependencies, run untrusted tools in an isolated environment, and require consent before writes, secret access or network actions.

The built-in audit described in the local v1.0 release is heuristic and is **not** a malware scanner or security guarantee.

Please report sensitive vulnerabilities privately using GitHub's security advisory feature instead of creating public issues containing exploits or credentials.
