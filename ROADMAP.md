# OmniForge Roadmap — 10K Star Ambition

Stars are earned by community adoption, not guaranteed by roadmap milestones.

## v1.0.0 — local capability layer (implemented)

- Python CLI and 10 operational script-backed skills.
- Token-conscious skill search / lazy reading.
- MCP stdio search/load/budget endpoints.
- VS Code MCP setup and agent-specific installer.
- 112 discovery candidates clearly marked as **not integrated**.
- Static audits, validation, tests, and CI.

## Beyond v1.0 — proposals, not shipped

- Compatibility/evaluation harness against leading AI coding agents.
- Agent-aware ranking based on task-type feedback, without storing personal prompts by default.
- Safe isolated tool execution using an actual sandbox/permission broker.
- Signed skill releases and SBOM/dependency provenance.
- Verified integrations for bpftrace, rr, mitmproxy, KiCad, esptool, Trivy, and other upstream tools.
- Optional provider-agnostic agent orchestration with human approval gates.
- Better Windows/WSL support, terminal UI and metrics dashboard.

## Community growth goals

| Target | Community-facing focus |
|---|---|
| 100 stars | Reliable one-line installation and useful examples |
| 1,000 stars | Verified integrations and contributions from real users |
| 5,000 stars | Cross-agent benchmarks and multi-platform packaging |
| 10,000 stars | Established project with sustained releases and independent adoption |

Do not automate stars or generate misleading activity. Prioritize demos, documentation, correctness and helpful reviews.
