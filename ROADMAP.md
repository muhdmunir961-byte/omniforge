# OmniForge Roadmap

## Vision
A portable, local-first capability layer for AI coding agents, with task-focused skill routing and minimal unnecessary context.

## v1.0 core release (locally tested)
- CLI and metadata-based skill router
- 10 script-backed skills
- JSON-RPC MCP stdio bridge for search/load/budget
- VS Code setup and agent-specific installer
- 112 unverified upstream discovery candidates
- 23 locally passing tests

## Future
- Reproducible public benchmark and CI quality gates
- Permissioned skill execution with sandboxing
- Verified third-party integrations and signed provenance
- Incremental repository indexing and token usage telemetry
- User-controlled multi-agent orchestration

GitHub stars are an adoption goal, not a guarantee.
